# AI Shield Quick Check — Ollama 安全快速评估（服务说明）

## 服务定位

面向已部署本地大模型服务（Ollama）的企业客户，提供一次快速、只读的
安全体检：确认服务是否暴露在公网、是否缺少认证、是否可被未授权访问，
并给出可执行的修复建议与正式评估报告。

## 检查内容（6 项，全部只读）

- 网络暴露：服务是否绑定所有接口、能否从外部访问
- 认证缺失：未认证能否读取模型列表
- CORS 配置：是否允许任意来源跨域访问
- 模型访问：未授权用户能否列出模型
- 资源滥用：是否具备速率限制
- 已知漏洞：对照公开漏洞情报匹配已知 CVE

评估不向模型发送生成请求、不修改配置、不执行破坏性测试。

## 交付物

- 中文 PDF 评估报告（含评估概览、委托信息、授权范围、执行摘要、
  风险发现与证据、严重级别、修复建议、覆盖范围与局限、复测状态）
- 原始 JSON 结果（结构化数据，便于二次分析）

## 价格与周期

- 单次授权评估：¥99 / 次（英文站固定展示 $15.00 / assessment）
- 周期：签署授权书后 1 个工作日完成（不含复测）

## 客户前置条件

1. 对目标主机与端口拥有所有权或书面授权
2. 签署《客户授权书》并确认《评估范围》
3. 评估期间目标服务保持可访问

## 局限声明

本服务为快速只读评估，不探测生成类风险（如提示词注入、训练数据泄露），
未确认项不代表安全；评估结果仅反映评估时段内的观察。
