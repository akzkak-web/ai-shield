## 二、授权动作范围

仅限以下动作：

1. 端口连通性检测；
2. 对已授权端口发起 HTTP 只读请求（识别服务类型、版本）；
3. 检查认证、CORS、模型列表访问、速率限制；
4. 将观察结果写入评估报告（JSON/PDF）。

## 三、禁止事项

评估方承诺不执行以下动作：破坏性测试、拒绝服务、修改配置或数据、
删除或下载模型、绕过认证、访问授权范围外的任何主机或端口。
